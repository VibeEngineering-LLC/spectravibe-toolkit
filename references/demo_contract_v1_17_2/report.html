Разложение мультиплетов (связанная подгонка по библиотечным интенсивностям)

Мультиплет M1 — связанная подгонка Ac-228 911 + 964.8 + 969 + Tl-208 860.6 кэВ

χ²/ν = 17.02 · ROI 120 кан · ступенчато-линейный континуум · закрытие Δ = -0.9%

Все три линии Ac-228 связаны через одну свободную активность A(Ac-228), площади распределены по библиотечным интенсивностям (25.8 % : 4.99 % : 15.8 % = 5.17 : 1.00 : 3.17). Tl-208 860.6 кэВ — отдельная активность; решилась в S = 0 (вклад правого крыла 860 в этот ROI пренебрежим). Закрытие Δ = −0.92 % (вместо −14.6 % в свободной подгонке) — модель физически согласована. Площади: S(911) = 116 996, S(964.8) = 22 628, S(969) = 71 649. Активность по любой из трёх линий — одна и та же: A(Ac-228) ≈ 1959 Бк/кг.

Мультиплет M2 — связанная подгонка Ac-228 1588 + 1630 + Bi-212 1620 кэВ

χ²/ν = 1.19 · ROI 119 кан · ступенчато-линейный континуум · закрытие Δ = -0.5%

Линии Ac-228 1588 и 1630 связаны через одну A(Ac-228), Bi-212 1620 — отдельная свободная активность. Связка позволила корректно вытащить центральную компоненту триплета (Bi-212 1620 ранее в свободной подгонке решалась в 0). Закрытие Δ = −0.51 %, χ²/ν = 1.19 — модель адекватна. Площади: S(1588) = 16 258, S(1620) = 2 172, S(1630) = 8 078. Bi-212 1620 даёт cps = 0.19 — на пределе детектируемости, но физически разделена.

1376 ± 135 Бк/кг
Лучшие линии: Ac-228 338 (+18%), Tl-208 583 (+11%), Ac-228 911 свободная подгонка (−8%). Метод σ по правилу F-91. Связанная подгонка M1 даёт A(Ac-228) ≈ 1959 Бк/кг (+61%) — расхождение между методами указывает на систематическую недооценку континуума под кластером 900-970 кэВ.

Что определяет цепочку Th-232

Однозначное подтверждение цепочки Th-232 — присутствие линии Tl-208 2614 кэВ (I_эфф = 35.83%) и сильной Pb-212 238 кэВ (I = 43.6%). Дополнительно цепочку подтверждают Ac-228 338 + 911 + 1588 и Bi-212 727. Источник изготовлен > 30 суток назад → цепочка в секулярном равновесии → A(Th-232) = A(Pb-212) = A(Ac-228) = A(Bi-212) = A(Tl-208) / 0.359.

Связанная подгонка мультиплетов M1 и M2

Принцип: все линии одного нуклида в мультиплете связываются через одну свободную активность; их площади распределяются по библиотечным интенсивностям. Линии разных нуклидов имеют независимые активности. Решается как линейная задача наименьших квадратов с неотрицательными переменными (NNLS / lsq_linear).

Эффект: закрытие мультиплета улучшается с −14.6 % до −0.92 % (M1) и с неопределённого до −0.51 % (M2); Bi-212 1620 теперь не исчезает в ноль. Все линии одной нуклиды дают согласованную активность.

Почему U-238 / Ra-226 цепочка не определяется

Имя файла связывает источник только с торием. В фоновом спектре линии Pb-214 295/352 и Bi-214 609/1764 отсутствуют. По правилу F-89d при привязке к торию и отсутствии «квартета» Bi-214 цепочка U-238 / Ra-226 не подтверждается.

Почему линия 238 кэВ даёт завышенную активность (+69%)

Pb-212 238.6 кэВ — самая яркая линия в спектре. Подгонка Гауссом + ступенчато-линейным континуумом даёт χ²/ν = 166: модель не описывает левый низкоэнергетический хвост NaI. Для корректной оценки нужна модель peak_image — Гаусс + экспоненциальный левый хвост + Комптон-ступенька (модуль F-90).

Линия 2614 кэВ — на границе кривой эффективности

2614 кэВ сидит ровно на верхнем краю Zone_2 полинома .efa. На самом краю один якорь определяет точку и ковариация коэффициентов раздувает σε из табличных 3.3 % до полиномиальных 38 %. По правилу F-107 наша система берёт σε из ковариации полинома; вес линии в взвешенном среднем пренебрежим.

Зона 70-90 кэВ — без покомпонентного разложения

Кластер 73-90 кэВ — композит Pb K-РИ от ВК Pb-212 239 + Tl-208/Bi-212 + Th-228 84.37 + Pb-флуоресценция. На NaI 63×63 с ПШПВ ≈ 12 кэВ при шаге 2-3 кэВ покомпонентное разделение физически невозможно (F-110). Кластер не входит в расчёт активности.
