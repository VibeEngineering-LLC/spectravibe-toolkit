## Протокол сверки наших расчётов с этим эталоном

При любом прогоне Th-232 Marinelli 0cm через `scripts/run_plan_a.py` сравнение идёт по схеме:

### 1. Энергии пиков (E_max, кэВ)
- Допуск: |E_наш − E_LSRM_calc| ≤ max(`energy_uncertainty_keV`_LSRM, 0.5 кэВ).
- Сверка по столбцу `energy_keV` (а не `library_energy_keV`).

### 2. ПШПВ (FWHM, кэВ)
- Точечный: |FWHM_наш − `fwhm_keV`_LSRM_изм| ≤ max(`fwhm_uncertainty_meas_eV`/1000, 2 кэВ).
- Кривой: коэффициенты нашего FWHM(E) согласованы с 14-anchor LSRM-полиномом в общем диапазоне на ±10% (или явное обоснование, почему generic-default используется).

### 3. Площади (counts)
- |area_наш − `area_counts`_LSRM| ≤ 2 × max(`area_uncertainty_counts`, σ_наш) при PASS.
- 1×σ → marginal; >3σ → FAIL c расследованием (мультиплет, форма пика, фон).

### 4. Активности (Бк/кг)
- Сертификат остаётся первичным (cert_zcheck.json в каждом прогоне).
- Сравнение с LSRM `activity_lsrm.json` — вторичное; до выяснения единиц столбца «Активность» отношение `lsrm_Bq / 1.6` сравнивать с нашим Бк/кг.

### 5. Параметры формы пика
- Степень фона зоны (`bg_polynomial_degree`): сейчас у нас = 1 везде, LSRM использует 1/2/3 по энергии. Расхождение допустимо, но фиксируется как сторонний пункт для возможного апгрейда `_continuum_grid_for_peak`.
- Знак ступеньки (`step_value`): LSRM допускает оба знака, наш `_erfc_step_continuum` пока всегда «нисходящий» (left > right). На 580 кэВ LSRM даёт step = −0.00567 → наш erfc-step в этой зоне будет «не той ориентации».
- Тип пика: LSRM «Асимметричный Гауссиан» (разные σ_L/σ_R), у нас симметричный. На низких энергиях это часть систематики.
