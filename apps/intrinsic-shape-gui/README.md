# IntrinsicShapeGUI — окно для калибровки по форме собственных структур LaBr3

> **Только для AtomNano 5 PRO LaBr3.** Программа проверена и настроена под этот прибор: пресеты, опоры
> автопресета, окна собственных структур и шкала ниже 100 кэВ получены по спектрам AtomNano 5 PRO LaBr3
> (2048 и 8192 каналов). На других детекторах результат не гарантирован.
>
> **Тестовая версия** (бета): для проверки метода, не для отчётных измерений.

Программа с окном для модуля `gamma.calibration.intrinsic_shape` (каталог `scripts/` этого репозитория; метод и
пороги — `skills/intrinsic-shape-cal/SKILL.md` и `references/intrinsic_shape_calibration.md`): выбрать фон и образец
(BecqMoni XML), совместить их по форме собственных структур кристалла или откалибровать по пикам пробы, вычесть фон
и получить разностный XML для BecqMoni — с графиками и числами качества.

## Запуск

Готовая программа — архив `IntrinsicShapeGUI-<версия>-win64.zip` в Releases репозитория. Распаковать архив целиком и
запускать `IntrinsicShapeGUI.exe` из распакованной папки `IntrinsicShapeGUI` (рядом с exe должна лежать папка
`_internal`; exe отдельно от неё не работает). Windows 10/11 x64, Python не нужен. Заголовок окна помечен
«тестовая версия».

## Вкладки

1. **Файлы спектров** (верх окна): «Обзор…» у строк «Фон» и «Образец»; под ними — живое время, число каналов, k.
   Число каналов любое (2048, 8192 …). **«Новый спектр»** сбрасывает файлы и все результаты (при несохранённом
   результате спрашивает).
2. **1. Совместить** — совмещение образца с фоном по форме: найденные опоры (пик ~37 кэВ, сумм-пик La-138, β-край)
   и поле ручной поправки, режим «линии образца», исключённые окна в кэВ, K-40 под сумм-пиком, окна собственных
   структур (справочно), h, χ²/ndf и «Требует толкования».
3. **2. Шкала** — реперы пары (собственные структуры фона и линии образца; Lu-176 — по пресету) с ветвью шкалы,
   график ветви ниже 100 кэВ с полосой неопределённости; по желанию — спектр Am-241/Ba-133 того же прибора.
   Точки ПШПВ пары переносятся на вкладку «ПШПВ».
4. **2б. Шкала по пробе** — для пробы со своими линиями. Щелчок по пику спектра пробы → подгонка → выбор линии из
   ядерных данных или ввод энергии вручную; повтор уже взятой линии не добавляется. Кнопки «Удалить репер»,
   «Очистить», «Сохранить набор…» / «Загрузить набор…» (JSON; при загрузке на другой спектр того же прибора реперы
   переподгоняются, усиление проверяется), «Шкала по пробе». Ниже — сводка решения, таблица «файл / реперы» и
   строка «для замены нужно: …; сейчас: …», если шкала по реперам не рекомендована. По умолчанию в XML пишется
   калибровка файла пробы. Кнопка **«Записать шкалу по реперам»** доступна только при рекомендации гейта; она гаснет
   при смене пары, при «Новый спектр» и на время любой задачи. Разность затем строится на сетке пробы.
5. **3. Вычесть** — папка и имя результата, **«Живое время файла»: образца (по умолчанию) или фона** (разность всегда
   в cps: net_cps = S/LT_s − B/LT_b; в файл пишется net_cps·LT выбранного спектра, cps в BecqMoni от выбора не
   меняется), кнопка «Вычесть и сохранить». Создаются `имя.xml` (отрицательные каналы обнулены) и
   `имя_со_знаком.xml`; в оба вписан блок ПШПВ. Исходные файлы не изменяются.
6. **График** — образец, фон·k, разность; **ось Y: «cps на канал» (по умолчанию) или «Отсчёты на канал»**; каналы
   или кэВ, лог. шкала, метки реперов, «обнулённая / со знаком».
7. **ПШПВ** — точки «канал:ширина», модель, «Значения для настроек прибора BecqMoni» (FWHM_AT_0 / Ch_Fwhm /
   Width_Fwhm), «Копировать в буфер». Файл прибора BecqMoni перед правкой скопировать, BecqMoni закрыть.
8. **Фоны** — проверка папки фонов (дубли, группы); разложение фона (доля K-40).
9. **Самопроверка** — мутационный тест метода на выбранной паре (несколько минут).

Все расчёты идут в фоновом потоке; во время задачи в строке состояния — счётчик «прошло мм:сс» и кнопка
**«Отмена»** (операция останавливается после текущего шага). Внизу — журнал (тот же вывод, что у командной строки
модуля). Ошибки входных данных показываются сообщением, без трассировки.

## Ограничения

Опоры автопресета и окна — для LaBr3 AtomNano 5 PRO; ниже 37 кэВ шкала — экстраполяция без спектра Am-241/Ba-133;
полином в XML (не выше 4-й степени — ограничение BecqMoni) не повторяет ветвь ниже 60 кэВ (до ~3 кэВ).
Калибровка по пробе: общая систематическая ошибка энергий всех реперов не ловится (только предупреждение по 511 кэВ
и собственным структурам); при 6–8 реперах шкала по реперам обычно не проходит гейт; при исправной
калибровке файла гейт изредка рекомендует шкалу по реперам, которая на отложенных линиях хуже примерно на 1 кэВ. Если «образец» — продолжение того же измерения, что и фон, окно
предупреждает. Подробно — методика модуля.

## Для разработчика

- Код: `src/isgui/` — `backend*.py` (обработчики без интерфейса), `widgets.py` (фоновый поток, журнал, графики,
  счётчик времени), `peakpicker.py` (выбор пиков), `panels.py`, `main_window.py` (окно), `__main__.py`.
  Модуль расчёта не копируется: импорт из `scripts/` корня репозитория (`__main__.py` добавляет его в путь).
- Окружение: `python -m venv <папка>` и `pip install -r requirements.txt`. Запуск из исходников (из этой папки):
  `set PYTHONPATH=src` и `python -m isgui`.
- Сборка: `build.bat` (PyInstaller, one-folder, `IntrinsicShapeGUI.spec`; модуль и данные — из `scripts/` и `data/`
  корня репозитория). Python сборки — переменная `ISGUI_PYTHON` (иначе `python` из PATH). Результат —
  `dist/IntrinsicShapeGUI/` (в git не входит).
- Тесты окна: `python tests/test_peakpicker.py`, `tests/test_net_plot.py`, `tests/test_op_timer.py` (без окна на
  экране, `QT_QPA_PLATFORM=offscreen`); данные — фикстуры `tests/fixtures/intrinsic_shape/` репозитория.
- Приёмка: `tests/acceptance.py` — совпадение с командной строкой модуля по DataPoint, мутации, плохие входные
  файлы, цепочка кнопок. Необязательные шаги на внешних данных включаются переменными окружения: `ISGUI_REF_DIR`
  (замороженный выход для регрессии DataPoint), `ISGUI_PAIR8_BG`, `ISGUI_PAIR8_SAMPLE`, `ISGUI_PAIR8_BG_IND`
  (пары 8192), `ISGUI_SOIL_BG`, `ISGUI_SOIL_SAMPLE` (образец с линиями); без них шаги пропускаются с пометкой
  `[SKIP]`. Критерии — `tests/acceptance_criteria.json`; `tests/acceptance_mutations.py` — таблица «мутация →
  краснеет ли проверка»; `tests/exe_smoke.py` — запуск собранного exe и время старта.
