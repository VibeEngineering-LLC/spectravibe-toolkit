# Эталонные спектры Gamma-1S в формате BecqMoni

Набор аттестованных источников, измеренных на спектрометрическом комплексе
**Гамма-1С** (детектор УДС-ГЦ-63×63-USB №SN-01, NaI(Tl) 63×63 мм, ПО Lsrm SpectraLine).
Каждый файл самодостаточен: спектр образца и фон той же геометрии лежат в одном XML —
фон записан как `<BackgroundEnergySpectrum>`, отдельный файл подгружать не нужно.

Всего записей: **40** в 5 геометриях.
Исходные `.spe` — в соседней папке `../reference_kits/`, конвертация —
`scripts/convert/reference_kits_to_becqmoni.py` (идемпотентна).

## Как читать таблицы

**Активность** взята из поля `COMMENT` заголовка LSRM — это паспорт источника
на опорную дату, а не результат измерения. Где указано «Бк/кг», это удельная
активность наполнителя, где «Бк» — активность точечного источника. Распад к дате
измерения не пересчитан.

Отдельно про смесь РИСН-379: в `.spe` поле `COMMENT` хранит **одну** строку, поэтому
в таблице стоит только один нуклид из четырёх (Am-241 для Маринелли, Cs-137 для
Дента и Петри-60). Полный состав источника в спектрах не записан.

**Единицы.** BecqMoni хранит `Weight` в килограммах и `Volume` в литрах, LSRM `.spe` —
в граммах и миллилитрах. При конвертации выполняется деление на 1000; колонка
«масса» ниже — исходная, в граммах.

**Мёртвое время** посчитано как `(real − live) / real`, по временам из заголовка.

`.efr` — точки эффективности по опорным источникам, `.efa` — описание геометрии
и матрицы образца.

прибор не переносятся даже при одинаковой модели — различаются усиление ФЭУ,
