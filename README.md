# spectravibe-toolkit

Публикуемая часть проекта **SpectraVibe** — инструменты и методика анализа гамма-спектров,
упакованные так, чтобы ими могли пользоваться агенты и скрипты на любой машине,
без доступа к рабочему репозиторию проекта.

Методическая основа — Gilmore & Joss, *Practical Gamma-ray Spectrometry*, 3rd Ed. (Wiley, 2024),
с уточнениями из Lsrm *Algorithmic Foundations* (2025). Ядерные данные — ENSDF/NuDat 3 (NNDC), LNHB.

## Что внутри

| Путь | Содержимое |
|---|---|
| `SKILL.md` | Рабочая инструкция: двухпроходный сценарий анализа от метаданных до MDA. Точка входа для агента. |
| `scripts/gamma/` | Библиотека: ввод-вывод форматов, поиск пиков, калибровка, идентификация, деконволюция мультиплетов, активность и MDA, дозовые коэффициенты, отчёты. |
| `scripts/*.py` | Утилиты командной строки — `analyze_spectrum.py`, `convert_spectrum.py`, `run_skill.py` и др. |
| `tests/` | Тесты по шагам конвейера (`step01_io` … `step11_reporting`) плюс снапшот-фикстуры. |
| `detectors/` | Спектры, паспорта и калибровки 11 гамма-спектрометров: NaI, HPGe, LaBr₃, CdTe/CZT, RadiaCode, AtomSpectra. Сводка с количеством — в [SPECTRA_MAP.md](SPECTRA_MAP.md). |
| `references/` | Контракт демо-отчёта, кэш ядерных данных IAEA, ground-truth фикстуры ЛСРМ, библиотеки нуклидов. |
| `docs/` | Методические заметки и порядок запуска. |
| `ARCH.md`, `FORMAT_REGISTRY.md`, `NOTES_v1.7_methodology.md` | Архитектура, реестр поддерживаемых форматов, методические выводы. |

Поддерживаемые форматы спектров: `.spe`, `.chn`, `.n42`, `.mca`, `.spc`, `.spm`, `.txt`, `.csv`
— полный список и разбор особенностей в `FORMAT_REGISTRY.md`.

## Чего внутри нет и почему

Репозиторий публичный, поэтому в него намеренно **не** включено:

- `books_library/` — учебники и мануалы третьих лиц (Gilmore, Будыка, Шендрик, ORTEC, ЛСРМ). Чужой копирайт.
- `references/_ocr_output/`, `references/_extracted_corpus/` — OCR-производные тех же книг.
- `knowledge_*.json` — RAG-индексы, построенные по этому корпусу (содержат дословные фрагменты).
- `detectors/*/raw_lsrm/` — сырые рабочие деревья ЛСРМ; остаются на машине оператора.
- `detectors/Gamma-1S/reference_spectra/lsrm/` и `becqmoni/` — массовая выгрузка поверок 2016 и 2024,
  1 171 файл. Публикуются только курированные наборы `reference_kits/` и `reference_kits_becqmoni/`:
  пары «образец + фон» по геометриям, с описью, паспортными активностями и кривыми эффективности.
- Альфа- и рентгеновские классы ЛСРМ (`ADA_AlphaDuoSmall`, `Simple_Alpha`, `Simple_SiLi`) — репозиторий
  про гамма-спектрометрию.
- Внутренние рабочие каталоги проекта (переписка агентов, аудиты, черновики релизов).

Функции, которым нужен книжный корпус (RAG-цитирование первоисточников), без него работать не будут —
всё остальное самодостаточно.

Приборы и источники обозначены внутренними метками вида `SN-nn` и `SRC-nn`.

## Быстрый старт

```bash
python -m pip install -e .
python scripts/analyze_spectrum.py path/to/spectrum.spe
```

Python ≥ 3.9. Зависимости: numpy, scipy, matplotlib, reportlab, defusedxml.

Прогон тестов:

```bash
python -m pytest
```

## Для агентов

Точка входа — `SKILL.md`: он описывает двухпроходный порядок работы (сначала метаданные,
детекция среды, калибровка и распознавание фона; затем строгая идентификация по изолированным
характеристическим линиям, отношениям интенсивностей и цепочкам распада). Там же — правила
классификации вторичных пиков, идентификации элементов по XRF-картинам Kα/Kβ, поправки на
мёртвое время, индекс доверия и расчёт MDA по ISO 11929.

## Замечание о путях

Несколько операторских утилит (`scripts/data/ocr_queue.py`, `scripts/gamma/dose/lsrm_coeffs.py`)
содержали жёстко прописанные пути рабочей машины. Они заменены на плейсхолдеры
`<USERPROFILE>`, `<GDRIVE>`, `<REPO>` — подставьте свои перед запуском. Основной конвейер
анализа от этого не зависит.
