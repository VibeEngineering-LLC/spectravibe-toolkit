# intrinsic-shape-cal — калибровка по форме собственных структур

Модуль toolkit: `scripts/gamma/calibration/intrinsic_shape/`; методика с формулами, порогами и ограничениями —
`references/intrinsic_shape_calibration.md` (читать перед интерпретацией результатов; калибровка по пробе — п. 14
раздела 2). Запуск из корня репозитория: `PYTHONPATH=scripts python -m gamma.calibration.intrinsic_shape <подкоманда> ...`
(при установленном пакете — без `PYTHONPATH`). На Windows с кириллицей в путях — `PYTHONIOENCODING=utf-8`.

## Когда применять

- Детектор с собственной активностью (LaBr3(Ce), CeBr3, LYSO/LuAG) и два спектра одного прибора, снятые в разное
  время: фон и образец разных дней, дрейф усиления от температуры, перезапуск.
- Нужно вычесть фон «другой сессии» без ложных диполей у сумм-пика La-138 и α-полос; разность — в cps.
- Проба со своими линиями (руда, грунт, медальон), собственные структуры в ней видны плохо — калибровка по пробе:
  реперы по пикам пробы, фон переводится на шкалу пробы (`sample-cal`).
- Любое число каналов (2048, 8192 …) и усиление LaBr3.
- BecqMoni показывает «нет модели разрешения» у разностного спектра — нужен блок `SqrtFwhmCalibration`
  или параметры прибора FWHM_AT_0 / Ch_Fwhm / Width_Fwhm.
- Сколько K-40 сидит под сумм-пиком La-138; какие файлы фонов в папке — дубли.

## Когда НЕ применять

- Кристалл без собственной активности (NaI, HPGe, CZT) — регистрировать по форме нечего.
- Неэкранированный фон с сильными внешними линиями — собственные структуры подавлены; только `decompose`.
- Другой кристалл (CeBr3, LYSO) без своего эталона опорных структур (`presets/labr3_reference.json` — для LaBr3).
- Точная шкала ниже 37 кэВ без внешнего источника: ветвь ниже 100 кэВ там — экстраполяция (полоса печатается).
- «Образец» — продолжение того же измерения, что и фон (вложенная пара): разность не «образец минус фон»,
  печатается предупреждение; нужен независимый фон.

## Что поддерживается

- **Автопресет**: в фоне находятся пик ~37 кэВ, сумм-пик La-138 и β-край, окна пресетов пересчитываются в каналы
  прибора. Ручная поправка — `--anchors-ch A37 SUM [EDGE]`, отключение — `--no-auto`; явные `--mask`/`--anchor-*` важнее.
- **Образец со своими линиями**: `register --robust auto` — подложка, комптоновские края и K-40 под сумм-пиком
  моделируются, окна линий исключаются; печатаются окна в кэВ, χ²/ndf до/после и K-40 ± σ. Несошедшаяся
  устойчивая регистрация — итог не принимается. Окна собственных структур `[STRUCT]` — справочно, в итог не входят.
- **Реперы и ПШПВ по паре**: Lu-176 — по пресету, иначе линии образца из разности по `data/nuclides.json`.
- **Шкала ниже 100 кэВ**: ветвь с непропорциональностью и ступенью на K-крае La 38.925 кэВ; реперы — пик ~37 кэВ
  (`--e37`), K-рентген Hf/Pb, Lu-176 88 кэВ, по желанию спектр Am-241/Ba-133 (`--source`, `--source-nuclide`).
  В XML — полином ≤ 4-й степени (ограничение BecqMoni), если он не портит шкалу выше 100 кэВ больше 1 кэВ.
- **Разность в cps**: net_cps = S/LT_s − B/LT_b; в XML — net_cps·LT_out целыми, `--lt-out sample|bg` (по умолчанию
  образца); cps в BecqMoni от выбора не зависит.
- **Калибровка по пробе** (`sample-cal`): разность на сетке пробы (фон переводится по видимым собственным структурам
  `--mode visible` или через энергии `--mode energy`; по умолчанию — автоматически). Шкала XML по умолчанию —
  калибровка файла пробы; шкала по реперам пишется только с `--use-reper-scale` и только если гейт её рекомендовал:
  ≥ 4 разных реперов от 100 кэВ, охват ≥ 60 % области 100–2700 кэВ с реперами в нижней и верхней трети, степень
  ≤ n − 3 (3 и выше — от 8 реперов), LOO ≤ 3 кэВ, запас против калибровки файла (×1.5 и +1 кэВ), вето по ≥ 3
  независимым линиям (хуже файла больше чем на 1 кэВ). Набор реперов — JSON, переносится на другой спектр того же
  прибора с проверкой усиления.

## Порядок работы (пример на тестовой паре репозитория)

Результаты пишутся только туда, куда указывают ключи `--out*`/`--xml-out`; входные спектры не изменяются.

```bash
F=tests/fixtures/intrinsic_shape
M="python -m gamma.calibration.intrinsic_shape"
mkdir -p out
# 1. совмещение по форме: h, ковариация, список минимумов (1-2 с; --profiles -- медленнее)
$M register --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --out out/h.json
# 2. энергетическая шкала фона по реперам (пресет LaBr3 + Lu-176), невязки и LOO
$M ecal --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --h out/h.json --out out/ecal.json
# 3. разность -> два XML для BecqMoni (обнулённый и со знаком) с блоком ПШПВ; --lt-out sample|bg
$M subtract --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --h out/h.json --ecal out/ecal.json \
   --out-zeroed out/net.xml --out-signed out/net_signed.xml
# 3б. калибровка по пробе: разность на сетке пробы; шкала по реперам -- только с --use-reper-scale
$M sample-cal --bg $F/labr3_8192_background.xml --sample $F/labr3_8192_sample_th_u.xml --repers <набор_реперов.json> \
   --out-zeroed out/net_s.xml --out-signed out/net_s_signed.xml [--mode visible|energy] [--use-reper-scale] [--lt-out bg]
# 4. ПШПВ отдельно: дописать блок в копию XML или выдать умолчание прибора BecqMoni
$M fwhm --points 29.20:2.47 142.87:6.14 211.97:7.29 338.14:8.62 847.10:11.63 \
   --xml-in out/net_signed.xml --xml-out out/net_signed_fwhm.xml --ecal out/ecal.json
$M fwhm --points 29.20:2.47 847.10:11.63 --device   # FWHM_AT_0 / Ch_Fwhm / Width_Fwhm
$M fwhm --measure out/net.xml --channels 143 212 338 --fwhm0 8 --points 29.20:2.47 847.10:11.63
# 5. фоны: дубли и группы; собственная/внешняя часть и доля K-40
$M bg-inventory <папка_фонов> --recursive
$M decompose --ref <экранированный_фон.xml> --unshielded <фон1.xml> <фон2.xml> --ecal <c0> <c1> <c2>
# 6. мутационный тест метода на паре (несколько минут)
$M selftest --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml [--alt-bg <фон другой даты.xml> ...]
```

Ключи `register`: `--mask LO HI`, `--anchor-bg/--anchor-sample`, `--coarse-window`, `--robust auto|on|off`, `--z-peak`.
У `register/ecal/subtract/selftest`: `--no-auto`, `--anchors-ch A37 SUM [EDGE]`. `ecal`: `--no-low`, `--e37`, `--no-37`,
`--source --source-nuclide`. `subtract`: точки ПШПВ и составная шкала — из JSON шага `ecal` (`--fwhm-points` —
вручную), `--xml-scale composite|main`, `--lt-out sample|bg`. `sample-cal`: `--bg --sample --out-zeroed --out-signed`
(обязательные), `--repers JSON`, `--mode visible|energy`, `--use-reper-scale`, `--lt-out sample|bg`, `--name`, `--date`.
`subtract/fwhm`: `--monotone-to 1.5` или `c2>=0`; `fwhm --device --n-ch N`.

Коды возврата `sample-cal`: 0 — файлы записаны; 2 — шкала по реперам не рекомендована, а запрошен
`--use-reper-scale` (причина в сообщении); 3 — прочие ошибки входных данных и файлов. У остальных подкоманд
ошибка входных данных — код 2.

## Как читать вывод

- `[MIN]` — различные минимумы; несколько с Δχ² ≤ 4 — систематика отображения = их разброс (`[SYST]`).
  `[H] anchor pull z` — |z| > 2: якорь тянет решение.
- `[AUTO]` — опоры фона и их проверка; «НЕУВЕРЕННО» — задать `--anchors-ch`. `[ROBUST]` — режим, исключённые окна,
  K-40 под сумм-пиком. `[STRUCT]` — окна собственных структур, справочно: «в норме» при |z| ≤ 3; z χ² < −3 —
  подозрение на вложенную/зависимую пару; «не оценено» — линии образца скрывают > 1/3 половины окна.
- `[NET] формула` — разность в cps и выбранное LT_out. `[ACC] сумма` — справочно (у образца со своими линиями ≠ 0);
  `совпадает=True` — файл перечитан и равен расчёту.
- `[CAL] ... LOO` — LOO сумм-пика порядка −20 кэВ ожидаем, если выше 789 кэВ других реперов нет. `[LOWE]` — ветвь
  ниже 100 кэВ; «ниже 37 кэВ — экстраполяция» — нужен спектр Am-241/Ba-133.
- `[SCAL]` (sample-cal) — степень по LOO, независимые линии, обе шкалы (файла и по реперам), решение и причина;
  «для замены нужно: …; сейчас: …» — чего не хватает реперам. «возможна общая систематическая ошибка энергий
  реперов» — 511 кэВ или собственная структура LaBr3 на шкале по реперам дальше 1 ПШПВ.
- `[FWHM] CheckCalibration: годен=True ... запас` — запас должен быть заметно > 0.
- `selftest`: `ИТОГ (по НОВЫМ провалам)` — каждая мутация должна дать ≥ 1 новый провал; известные провалы исправной
  версии — `known_base_failures` пресета.

## Ограничения (кратко; подробно — в методике)

Шкала по форме держится на сумм-пике La-138 и β-крае, если у образца нет линий выше 789 кэВ; ниже 37 кэВ —
экстраполяция без внешнего источника; полином для XML не повторяет ветвь ниже 60 кэВ (до ~3 кэВ); K-40 ~9 % под
сумм-пиком эталонного фона; модель ПШПВ по 3–7 точкам (невязки до ±9 %). Калибровка по пробе: общая систематическая
ошибка энергий всех реперов гейтом не ловится (только предупреждение при расхождении > 1 ПШПВ); при 6–8 реперах
LOO обычно 4–9 кэВ — замены нет; при исправной калибровке файла гейт изредка рекомендует шкалу по реперам, которая
на отложенных линиях хуже примерно на 1 кэВ. Проверено на одном приборе (2048 и 8192 каналов).
