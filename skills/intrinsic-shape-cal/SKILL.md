# intrinsic-shape-cal — калибровка по форме собственных структур

Модуль toolkit: `scripts/gamma/calibration/intrinsic_shape/`; методика с формулами, ограничениями и числами —
`references/intrinsic_shape_calibration.md` (читать перед интерпретацией результатов).
Запуск из корня репозитория: `PYTHONPATH=scripts python -m gamma.calibration.intrinsic_shape <подкоманда> ...`
(при установленном пакете — без `PYTHONPATH`). На Windows с кириллицей в путях — `PYTHONIOENCODING=utf-8`.

## Когда применять

- Детектор с собственной активностью (LaBr3(Ce), CeBr3, LYSO/LuAG) и два спектра одного прибора, снятые в разное
  время: фон и образец разных дней, дрейф усиления от температуры, перезапуск.
- Нужно вычесть фон «другой сессии» без ложных диполей у сумм-пика La-138 и α-полос.
- Нужна шкала, когда внешних реперов мало, а собственные пики есть.
- BecqMoni показывает «нет модели разрешения» у разностного спектра — нужен блок `SqrtFwhmCalibration`
  или параметры прибора FWHM_AT_0 / Ch_Fwhm / Width_Fwhm.
- Сколько K-40 сидит под сумм-пиком La-138; какие файлы фонов в папке — дубли.

## Когда НЕ применять

- Кристалл без собственной активности (NaI, HPGe, CZT) — регистрировать по форме нечего.
- Неэкранированный фон с сильными внешними линиями — собственные структуры подавлены; только `decompose`.
- Шкала ниже ~60 кэВ: полином отклик не описывает (непропорциональность, пик ~37 кэВ — K-каскад Ba).
- Другой прибор/число каналов без перенастройки окон: пресеты заданы в каналах конкретного AtomNano 5 PRO LaBr3, 2048 кан.

## Порядок работы (пример на тестовой паре репозитория)

Все результаты пишутся только туда, куда указывают ключи `--out*`/`--xml-out`; в примере — в папку `out/`
(создаётся первой командой); входные спектры не изменяются.

```bash
F=tests/fixtures/intrinsic_shape
M="python -m gamma.calibration.intrinsic_shape"
mkdir -p out
# 1. совмещение по форме: h, ковариация, список минимумов (1-2 с; --profiles -- медленнее)
$M register --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --out out/h.json
# 2. энергетическая шкала фона по реперам (пресет LaBr3 + Lu-176), невязки и LOO
$M ecal --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --h out/h.json --out out/ecal.json
# 3. разность -> два XML для BecqMoni (обнулённый и со знаком) с блоком ПШПВ
$M subtract --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml --h out/h.json --ecal out/ecal.json \
   --fwhm-points 29.20:2.47 142.87:6.14 211.97:7.29 338.14:8.62 847.10:11.63 \
   --out-zeroed out/net.xml --out-signed out/net_signed.xml
# 4. ПШПВ отдельно: дописать блок в копию XML или выдать умолчание прибора BecqMoni
$M fwhm --points 29.20:2.47 142.87:6.14 211.97:7.29 338.14:8.62 847.10:11.63 \
   --xml-in out/net_signed.xml --xml-out out/net_signed_fwhm.xml --ecal out/ecal.json
$M fwhm --points 29.20:2.47 142.87:6.14 211.97:7.29 338.14:8.62 847.10:11.63 --device   # FWHM_AT_0 / Ch_Fwhm / Width_Fwhm
# измерить точки подгонкой на пиках разности (Lu-176 202, 307, сумма 509) + ядро сумм-пика La-138 из фона;
# точки с плохой подгонкой (отн. σ > 0.2 или ширина вне 0.4..2.5 от --fwhm0) отбрасываются с причиной
$M fwhm --measure out/net.xml --channels 143 212 338 --fwhm0 8 --points 29.20:2.47 847.10:11.63
# 5. фоны: дубли и группы; собственная/внешняя часть и доля K-40
$M bg-inventory <папка_фонов> --recursive
$M decompose --ref <экранированный_фон.xml> --unshielded <фон1.xml> <фон2.xml> --ecal <c0> <c1> <c2>
# 6. мутационный тест метода на паре (несколько минут); чужие фоны того же прибора -- дополнительные мутации
$M selftest --bg $F/labr3_background.xml --sample $F/labr3_lu176_sample.xml [--alt-bg <фон другой даты.xml> ...]
```

Ключи `register`: `--mask LO HI` (каналы функционала на шкале фона, по умолчанию 430 1700), `--anchor-bg/--anchor-sample`
(каналы якоря), `--coarse-window` (окно сильной структуры для грубого наклона). `subtract/fwhm`: `--monotone-to 1.5`
(ширина не убывает до канала 1.5·N) или `c2>=0`.

## Как читать вывод

- `[MIN] #i chi2 dchi2 ... h(29,337,845,1340,1610)` — различные минимумы; если несколько с Δχ² ≤ 4, систематика
  отображения = их разброс (`[SYST]`). Разброс h > 1 канала или минимум сетки на краю — в блоке «требует толкования».
- `[H] anchor pull z` — |z| > 2: якорь тянет решение, проверить окно якоря.
- `[CAL] ... невязка ... LOO` — LOO сумм-пика порядка −20 кэВ ожидаем (выше 789 кэВ других реперов нет).
- `[FWHM] CheckCalibration: годен=True ... запас за N-1` — запас должен быть заметно > 0 (вершина параболы за краем шкалы).
- `[ACC] сумма net ... (z=...)` — |z| ≲ 2 при совпадении собственного фона; `совпадает=True` — файл перечитан и равен расчёту.
- `selftest`: `ИТОГ (по НОВЫМ провалам)` — исправная версия допускается только с известными провалами
  (`known_base_failures` пресета, сейчас `fitB->A|alpha3:z_dip`), каждая мутация должна дать ≥ 1 новый провал.
  `reg:dchi2` печатается как INFO: это согласованность с аргминимумом, не правильность. Пункты «поймано только
  минимумом на краю скана» — хрупкая поимка (растяжение ±0.2 % с опорой 840).

## Ограничения (кратко; подробно — в методике)

Шкала держится на сумм-пике La-138 и β-крае; ниже ~60 кэВ полином негоден; K-40 ~9 % под сумм-пиком; модель
ПШПВ по 5 точкам (невязки до ±9 %); проверено на одном приборе (2048 каналов).
