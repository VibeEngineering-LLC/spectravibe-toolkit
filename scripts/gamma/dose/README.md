# gamma.dose — расчёт мощности дозы (МД) из гамма-спектра

Подскилл: строит кривую вклада в мощность дозы по энергии из гамма-спектра и
сравнивает три метода дозовой свёртки. Форма кривой (Σ=1) привязывается к внешнему
якорю МД прибора `MD_TOTAL` [мкЗв/ч].

## Три метода

| # | Название | Вес канала w(E) | ε детектора |
|---|----------|-----------------|-------------|
| (3) | ЛСРМ (эмпирич.) | `f10(E)·(μen/ρ)_air·E` | НЕ участвует |
| (2) | ICRP-74 (флюенс) | `h_Φ(E)` | НЕ участвует |
| (2+ε) | ICRP-74 + ε NaI | `h_Φ(E)/ε_tot(E)` | делитель |

Вклад канала в дозу = `w(E)·N(E)`, где `N = counts/live` (скорость счёта). Кривая
нормируется `Σ=1`; абсолют = `curve·MD_TOTAL`.

**ε входит ТОЛЬКО в метод (2+ε)** (делитель `1/ε_tot`). Методы (3) и (2) от ε не зависят
— поэтому их формы почти совпадают (кросс-валидация двух независимых методик).

## Формулы и провенанс данных

### (3) ЛСРМ
Источник: «Мощность дозы. Методика расчёта из спектра гамма-излучения»
(ВНИИФТРИ/ЛСРМ/Аспект, Менделеево-Дубна). Формула 4.2:
`Ẋ_K = D·G_K·E_K·(μen/ρ)_air`, затем `Ḣ*(10) = Σ_K Ẋ_K·f_K(10)`.
Константа поверки `D` опущена (скаляр) — считается ФОРМА. Табл.12.2 (`μen/ρ` воздух,
`f(10)`) — в `lsrm_coeffs.py:_T122`. Извлечено VLM-OCR (baidu/Unlimited-OCR),
провенанс `dose_curve/methodology_ocr/page_04/result.md` (§23-сверено).

### (2)/(2+ε) ICRP-74
`h_Φ(E) = H*(10)/Φ` [pSv·cm²] — ICRP Publication 74 (1996), Table A.21, внутр.стр.179 =
PDF-стр.194 (`ANIB_26_3-4.pdf`). Извлечено VLM-OCR, **§23-сверка 25/25 строк** против
`dose_curve/icrp74_data/verify_p194.jpg` (0 переворотов, 2026-07-06). Данные —
`icrp74_hphi.py:_A21`. Самотест: `h_Φ(662)=3.76`, `h_Φ(1461)=6.79`, `h_Φ(2614)=10.25` pSv·cm².

### ε_tot NaI(Tl) 2×2″
`ε_tot(E) = 1 − exp(−(μ/ρ)·ρ·d)`, ρ=3.667 г/см³, d=5.08 см (ρ·d=18.63 г/см²).
`μ/ρ` NaI — mixture-rule (Bragg) из NIST z11(Na)+z53(I), w_Na=0.153373 w_I=0.846627,
K-край йода 33.17 кэВ. Данные — `data/nai_mu_rho_nist.csv`; регенерация —
`data/build_nai_mu_rho.py`. Реперы: 352→0.92, 609→0.78, 1120→0.64, 1461→0.59,
1764→0.56, 2614→0.51.

## Честный физический предел

Спектр = counts по **задепонированной** энергии, не флюенс. Строгий counts→флюенс требует
полной матрицы отклика (Monte-Carlo). `ε_tot` — полная эфф. взаимодействия (НЕ фотопиковая):
первопорядковая поправка, **точна на фотопиках, приблизительна на комптон-континууме**
(частичный энерго-депозит там даёт заниженный счёт). Сравниваются ФОРМЫ кривых, не абсолют.
Каждое утверждение по спектру — со ссылкой на источник (anti-hallucination).

## CLI

```
    [--spectrum PATH] [--md-anchor 0.09] [--out-dir DIR]
```

- Выход: `compare_dose_methods.png` (3 панели: спектр / 3 кривые / ε(E)) + `.csv`.

## Точки расширения («расширяем возможности»)

1. **Другие форматы спектра** — сейчас `parse_spectrum` = минимальный XML. Врезка в
   `gamma.io.format_registry` даст .spe/.n42/.txt/RadiaCode.
2. **Per-detector ε** — `eps_tot(rho, d_cm)` уже параметризован; добавить каталог геометрий
   (RadiaCode CsI, HPGe, LaBr₃) → `detectors/<name>/`.
3. **Абсолютная доза** — заменить нормировку Σ=1 на матрицу отклика (Monte-Carlo) для
   абсолютного мкЗв/ч без внешнего якоря.
4. **Фотопиковая ε_ph** — отдельная кривая для строгого counts→флюенс на фотопиках.
